# Weekly Project Report Template — Default

This is the global default consolidated-report template. The AI fills each
section. A project's TL may override this template per-project (per FR §B.2.2);
the system tolerates structural variation.

When the AI generates a report, it produces output that matches the section
structure below — section names exactly as written, in the same order.
